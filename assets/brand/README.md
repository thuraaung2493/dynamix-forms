# dynamix-forms branding

Aligned with Thura Aung’s portfolio and the mm-nrc-converter / ts-expressor project family using the built-in image generation tool. The existing project mark is preserved in the shared blue palette.

- [dynamix-forms-logo.png](dynamix-forms-logo.png): transparent project logo.
- [dynamix-forms-social-preview.jpg](dynamix-forms-social-preview.jpg): 2:1 social preview, exported as JPEG below GitHub’s 1 MB upload limit.
- [PROMPTS.md](PROMPTS.md): editing and generation prompts.

Shared palette: blue `#28518D`, navy `#25313D`, pale blue `#A8C7F5`, and soft gray `#EDF0F3`.

Upload the JPEG in **Repository settings → General → Social preview → Edit → Upload an image**. Updating the README banner does not automatically change the GitHub social-preview setting.

[GitHub’s social-preview requirements](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
